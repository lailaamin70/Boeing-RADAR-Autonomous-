# Boeing RADAR for Autonomous Driving

## Repository Structure

- `dashboard/` – Project dashboard for presenting and exploring analysis results.
- `src/` – Reusable analysis code.
- `velocity_efficiency_report.ipynb` – Velocity and cross-sensor efficiency analysis report.
- `radar_lidar_pts.ipynb` – RADAR and LiDAR point analysis.
- `requirements.txt` – Python dependencies.
- `setup.sh` – Environment setup script for the dashboard.

# Boeing RADAR for Autonomous Driving

## Repository Structure

- `dashboard/` – Project dashboard for presenting and exploring analysis results.
- `src/` – Reusable analysis and data-processing code.
- `notebook/` – Development and exploratory notebooks used to support the main analysis notebooks.
- `results/validated/` – Validated intermediate tables and analysis outputs generated by the notebooks, retained for inspection and reuse.
- `velocity_efficiency_report.ipynb` – Main velocity and cross-sensor efficiency analysis.
- `radar_lidar_pts.ipynb` – RADAR and LiDAR point-based and sensor-condition analysis.
- `condition_velocity.ipynb` – Condition-based RADAR–LiDAR velocity analysis.
- `requirements.txt` – Python dependencies for the analysis environment.
- `setup.sh` – Environment setup script for the dashboard.

## Analysis Environment Setup

This environment is used for the TruckScenes data analysis and Jupyter notebooks.  
The dashboard/web application is configured separately.

### Python

Use Python 3.11.x.

`truckscenes-devkit==1.2.0` requires Python >= 3.8 and < 3.12.

---

### 1. Create a Virtual Environment

The examples below use `.venv` as the virtual environment name.  
You may use a different name if preferred.

#### Windows

```powershell
py -3.11 -m venv .venv
```

#### macOS / Linux
```bash
python3.11 -m venv .venv
```

### 2. Activate the Virtual Environment
#### Windows - PowerShell
```powershell
.\.venv\Scripts\Activate.ps1
```
#### macOS / Linux
```bash
source .venv/bin/activate
```
### 3. Install the analysis dependencies
```bash
pip install -r requirements.txt
```

### 4. Jupyter Notebooks
If using Jupyter notebooks, select the Python kernel from the virtual environment you created.
